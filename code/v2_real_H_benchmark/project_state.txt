------------------------------------------------------------------------
1. ONE-PARAGRAPH WHAT-AND-WHY
------------------------------------------------------------------------
Runaway electrons (RE) in the ADITYA-U tokamak can't be measured directly.
They emit hard X-rays (HXR) when decelerating; the detector records a
SMEARED version of that emission. Goal: recover the true RE energy
distribution from the measured HXR spectrum by DECONVOLUTION (MLEM /
Richardson-Lucy), following Khilkevitch 2013. Long-term: feed this
rule-based pipeline's outputs to train an ML model for real-time
monitoring during live campaigns.

------------------------------------------------------------------------
2. THE CORE EQUATION AND WHAT EACH SYMBOL IS
------------------------------------------------------------------------
   y = H x + n        (Khilkevitch Eq. 1, matrix form)

   x = true spectrum   (what we want to recover)
   y = measured spectrum (what the detector records)
   H = response matrix (the smearing the detector adds)
   n = noise (Poisson)

   Forward  (easy): x -> y , one matrix multiply  y = H @ x
   Backward (hard): y -> x , MLEM iteration  = "deconvolution"

   SCOPE NOTE: Khilkevitch is DETECTOR-ONLY. There x is a PHOTON spectrum
   and H is the detector response (DRF) alone. The bremsstrahlung layer
   H_e (electron -> photon) is OUR extension for the RE problem and is a
   SEPARATE LATER LAYER. Do not mix it into the benchmark.

------------------------------------------------------------------------
3. MENTAL MODEL OF THE PAPER'S FIGURE 1 (locked-in understanding)
------------------------------------------------------------------------
   Fig 1c dashed = true source spectrum            = x_true
   Fig 1b dots   = x_true smeared by detector      = y (measured)   [forward]
   Fig 1c solid  = MLEM's recovered spectrum        = x_recon       [backward/deconvolution]
   Fig 1b solid  = x_recon pushed back through DRF  = sanity check  [forward again]

   Fig 1a = detector response to a SINGLE monoenergetic photon, at

            samples of how the response shape morphs with energy; the
            other ~88 columns must be interpolated. (They are the
            PAPER's NaI detector, not ADITYA-U's.)

9. KEY PRINCIPLES LEARNED (don't relitigate)
------------------------------------------------------------------------
   - Direct inversion x = H^-1 y fails: ill-conditioned, amplifies noise,
     gives negative counts. MLEM fixes all three (iterative + non-negative).
   - MLEM handles CONTINUOUS spectra (the RE case), not just discrete lines.
     Discreteness is in the grid representation, not a restriction.
   - High-energy reconstruction is limited by STATISTICS (few counts near
     10 MeV), not by code. A good H can't fix starved data.
   - Tag every modeling choice [PHYSICS] vs [PLACEHOLDER] so it's defensible.
